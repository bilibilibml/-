千恋万花 · 本地网页运行版

双击“启动网页版.cmd”，再点“启动游戏”。
地址：http://127.0.0.1:8765/
需要 Python 3.10+，建议新版桌面 Chrome / Edge。
不运行原游戏 EXE；资源从本目录按需读取，不一次加载整个游戏。

点击正文或按回车推进，游戏菜单内可存档和读档。
网页存档位于当前浏览器的 IndexedDB，与原游戏存档相互独立。
保持使用同一浏览器和同一地址；清除该站点数据会移除网页存档。

兼容调整：软件渲染；标题使用游戏原有静态背景；略过两段动态厂商标志。
